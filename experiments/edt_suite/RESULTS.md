## 결론

- **논문 구조가 신호가 있는 데이터에서는 작동한다.** FNSPID(22종목)에서는 평가 순위 IC 가 0 근처였던 논문 구조(P0)가
  EDT 보도자료(4천여 종목, 5.4만 건)에서는 검증 +0.062 / 평가 +0.061 / 집단 내 +0.079 를 냈다.
- **개선 구조(P1: 논문의 다섯 모듈 그대로 + 주 신호 입력 확장)가 논문 구조보다 낫다.** 주 신호 입력을 [임베딩 PCA64 ‖ LLM 이벤트 속성 ‖ 발행 시점·주가 수준]으로 넓히자
  검증 +0.072, 평가 +0.085, 집단 내 +0.093 으로 올랐다. 재실행(P6)에서도 평가 +0.087, 집단 내 +0.098 로 재현됐다.
- **논문의 TCN·교차 어텐션이 기여한다.** 제거(P2)하면 검증 +0.072 → +0.057, 집단 내 +0.093 → +0.072 로 떨어진다.
- 임베딩 제거(P3)는 집단 내 순위 IC 를 +0.060 으로, LLM 속성 제거(P4)는 검증을 +0.054 로 낮춘다. 둘 다 필요하다.
- 순위 손실(P5 와 비교)은 뚜렷한 차이가 없다. Ridge 와의 앙상블은 검증에서 제안 구조 단독(가중치 1)이 선택됐다.
- 롱숏 수익은 Ridge 가 가장 크다(+77.6bp, t=3.44). 제안 구조는 +46~55bp(t≈2.1~2.3).
- 평가 구간이 한 번(2021-03~05)뿐이므로 모델 간 0.01~0.02 차이는 잡음일 수 있다. 거래비용 미반영이며,
  주가 $5 미만 종목이 많아 실제 거래 비용은 클 수 있다.
