## 결론

1. **데이터에 신호는 있다. 다만 약하고, 한 구간에 몰려 있다.**
   감성 점수 하나만으로 장중 뉴스 → 당일 등락률이 r = +0.06 (z = 6.2).
   마감 후 뉴스 → 다음날 등락률에는 신호가 없다 (r = +0.005).
2. **가장 믿을 만한 신호는 장 시작 전 뉴스 → 당일 등락률이다** (r = +0.11, 방향 53.9%).
   장중 후반(12시 이후) 신호(r = +0.07)는 이미 움직인 주가를 뒤따라 보도한 기사의
   영향이 섞였을 가능성이 크다.
3. **검증 구간(2023 상반기)에는 신호가 없다** (r = −0.017). 검증 MSE 로 에폭을 고르면
   사실상 무작위로 고르게 되어, 신경망 결과가 불안정했던 이유를 설명한다.
4. **1536차원 임베딩이 이 데이터 규모에서는 신호보다 잡음을 더한다.**
   같은 평가 구간에서 감성만 쓴 선형 모델(상관 +0.051)이 임베딩을 더한 모델(+0.032)과
   신경망(+0.014)보다 낫다. 파라미터 3.5M 에 학습 표본 1.7만 건이라 임베딩 경로가
   과적합한다.
5. 요약문에 회사명이 나오는 기사(62%)만 보면 신호가 약간 더 선명하다 (r = +0.076).
