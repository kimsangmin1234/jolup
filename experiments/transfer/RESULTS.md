## 해석

1. **EDT 로 학습한 모델은 FNSPID 이후 기간에서 크게 약해진다.** 순위 IC 는 +0.008 ~ +0.034 로 양수지만 EDT 안에서의
   +0.08 ~ +0.09 에 크게 못 미치고, 같은 집단 안 순위 IC 는 0 근처 또는 음수, 롱숏은 0 근처다.
   EDT 에서 배운 패턴 상당수(소형 회사 홍보성 보도자료의 되돌림, 저가주 효과)는 보도자료·소형주 표본에 특화된 것이며,
   대형주 뉴스 기사(FNSPID)로는 옮겨 가지 않는다.
2. **학습 모델 중에서는 개선 구조(P1, 논문 모듈 기반 신경망)가 가장 잘 옮겨 간다.** 이후 기간 순위 IC +0.034 이고
   발행 시점 세 집단(+0.054 / +0.034 / +0.028) 모두 양수다. 트리 모델(LightGBM)은 +0.008 로 가장 약하다.
3. **가장 잘 일반화된 것은 학습 없는 LLM 판단이다.** LLM 방향 규칙과 나쁜 뉴스 매도 규칙은 이후 기간에서 순위 IC +0.041,
   같은 집단 안 +0.054 ~ +0.060, 롱숏 +10 ~ +17bp(t≈1.9) 로 학습 모델보다 낫다. 두 데이터셋에서 공통으로 통하는 신호는
   '기사가 회사에 나쁜 새 정보를 담고 있는가'라는 의미 판단이다.
4. 겹치는 기간(458건)에서는 학습 모델이 좋지만(P1 +0.095) 표본이 작아 결론을 내리기 어렵다.

결론: 데이터셋 안에서는 학습 모델(개선 구조·앙상블)이 가장 좋지만, 다른 출처·기간으로 옮기면 LLM 의 의미 판단을 그대로 쓰는
단순 규칙이 더 견고하다. 실제 적용에는 대상 시장·뉴스 출처에서 다시 학습하거나, LLM 판단을 중심에 둔 단순한 구조가 안전하다.
