## 해석 (순위 IC 동률 처리 수정 후)

1. **EDT 로 학습한 모델은 FNSPID 이후 기간에서 크게 약해진다.** 순위 IC +0.008 ~ +0.034 로 EDT 안(+0.08 ~ +0.09)보다 훨씬 낮고,
   95% 신뢰구간이 모두 0 을 포함한다. 같은 집단 안 순위 IC 와 롱숏도 0 근처다. EDT 에서 배운 패턴 상당수(소형 회사 홍보성
   보도자료의 되돌림, 저가주 효과)는 보도자료·소형주에 특화돼 대형주 뉴스 기사로 옮겨 가지 않는다.
2. **순위 IC 기준으로는 개선 구조(P1, 논문 모듈 기반 신경망)가 가장 잘 옮겨 간다**(+0.034, 0 이하 확률 3.2%, 95% 구간 [−0.002, +0.070]).
   발행 시점 세 집단 모두 양수다. 트리 모델(+0.008)이 가장 약하다.
3. **학습 없는 LLM 규칙은 순위 IC +0.019 ~ +0.021 로 약하지만, 롱숏은 가장 크다**(+10 ~ +17bp, t≈1.9).
   예측값이 −1/0/+1 이라 순위 정보는 적지만, 나쁜 뉴스를 매도하는 방향 신호는 다른 데이터에서도 어느 정도 남는다.
   (이전 판의 규칙 순위 IC +0.041 은 동률을 데이터 순서로 끊은 계산 오류였다.)
4. 결론: 어떤 방법도 다른 출처·기간에서 95% 수준으로 유의한 예측력을 보이지 못했다. 실제 적용에는 대상 시장·뉴스 출처의
   데이터로 다시 학습하는 것이 필요하다.
